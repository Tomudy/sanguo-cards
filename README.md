# 三国武将卡 · 亲子项目

涛哥和儿子（10–12 岁）的三国杀周边。三件套：

| 文件 | 用途 |
|---|---|
| `print.html` | 打印实体卡牌，A4 每页 9 张，63×88mm 标准尺寸 |
| `game.html` | 网页版简化对战，15 位武将全部可玩，支持人机（三档强度）/ 同机双人 / 局域网，带战绩成就 |
| `启动局域网.bat` / `start_lan.py` | 一键开局域网对战（双击即开，自动弹浏览器） |
| `lan_server.py` | 局域网对战服务器（被上面两个脚本调用，也可直接运行） |
| `设计表.md` | 给孩子的设计表 + 技能设计小课堂 |
| `art/` | 15 张 AI 原创立绘（水墨 Q 版统一风格） |

## 玩法（简化规则）

- 牌库 75 张：杀 ×28、闪 ×12、桃 ×8、无中生有 ×6、**战术牌 ×11**、**诸葛连弩 ×1**、**装备 ×9**
- **战术牌**（细节见下文）：酒、决斗、过河拆桥、顺手牵羊——让每个回合除了
  "出杀 / 吃桃"之外有更多选择，也给了"拆掉对方八卦阵"这类反制手段
- **装备**：武器位、防具位各一格，装上就长期生效，不占手牌、不受手牌上限约束，
  同槽位装新的会替换旧的（旧装备进弃牌堆）。没有"距离"概念，武器不做攻击范围，
  改成各自独有的杀招特效
- **诸葛连弩**：全场唯一的神兵，弃掉它，**本回合出【杀】不再受次数限制**
  （张飞能从 2 刀连到 4 刀，1 刀武将直接翻倍）
  - "多一次出杀"是本作最稀缺的资源，所以这张牌会连带放大武将差距：
    关山（伤害 2）与关羽（首刀不可闪）收益最高。为此给关山上了锁——
    【猛力】改为每回合只加一次伤害、【斗志】不再残血多摸一张，
    换来的是连弩能真正"连发"而不失衡（见文末平衡数据）
- 每回合：摸 2 张 → 出牌 → 弃牌到手牌上限（= 当前体力，小将军按体力上限算）
- 出杀次数：神姜维 3；小将军、关羽、张飞、赵云 2；其余 1
- 每回合限吃 1 张【桃】（关羽【义释】除外，且他吃桃还能补牌）
- **判定**：翻一张"判定牌"只问颜色（红/黑由引擎随机给出，不消耗牌堆），
  目前只有【八卦阵】会用到
- **濒死**：体力被打到 0 **不立即判负**，进入濒死状态
  - 濒死者打出 1 张【桃】（或【酒】）自救 → 体力回到 1 点，继续游戏
    （濒死求桃不受"每回合 1 张桃"限制，可以连救）
  - 自己没救牌 → 询问对手是否出【桃】/【酒】相救（亲子玩法：爸爸可以放儿子一马）
  - 无人施救 → 真正阵亡，对手获胜
- 60 轮未分胜负判和

## 六件装备

| 装备 | 槽位 | 效果 |
|---|---|---|
| 青釭剑 ×2 | 武器 | 锁定技，你的【杀】无视对方的防具（八卦阵、白银狮子、护心镜全部失效） |
| 青龙偃月刀 ×2 | 武器 | 每回合限一次，你的【杀】被【闪】抵消后，可立即再使用一张【杀】（不占出杀次数） |
| 古锭刀 ×1 | 武器 | 锁定技，你使用【杀】时若对方没有手牌，此【杀】伤害 +2 |
| 八卦阵 ×2 | 防具 | 每回合限一次，需要出【闪】时可改为判定：红色视为你使用了一张【闪】 |
| 白银狮子 ×1 | 防具 | 锁定技，你受到的【杀】伤害最多为 1 点（技能直伤不受影响） |
| 护心镜 ×1 | 防具 | 锁定技，进入濒死时自动碎掉，体力回复至 1 点（只能保一次命） |

装备互相之间有明确的克制链：**青釭剑破一切防具，八卦阵赌运气挡刀，
白银狮子压制高伤单体（马超/关山/吕布），护心镜防爆发斩杀，古锭刀惩罚空手，
青龙偃月刀把"被闪"变成再来一刀**。AI 空槽时会主动装备，有更强的才换。

## 四张战术牌

| 战术牌 | 数量 | 效果 |
|---|---|---|
| 酒 | ×3 | 每回合限一碗：本回合下一张【杀】伤害 +1；**濒死时可当【桃】用** |
| 决斗 | ×3 | 由**对方先出【杀】**，双方轮流接，先接不上的一方掉 1 血（龙胆/勇烈可转换） |
| 过河拆桥 | ×3 | 拆掉对方一张牌：装备点名拆，手牌随机拆 |
| 顺手牵羊 | ×2 | 把对方一张牌**抢过来**：装备当场换上，手牌随机摸走 |

决斗是"谁的杀多谁赢"的明牌消耗战——对方先出杀，所以对方空手时发起直接白赚；
拆桥和顺手是装备系统的反制面：再贵的刀也可能被拆，抢来的装备自己还能用。
AI 会优先动对方的装备、抢自己空槽位的、决斗前会数双方手里的杀。

## 花色与战力点数

选将卡（和打印出的实体卡）卡角像扑克牌一样带两个角标：**花色 = 势力，数字 = 战力点数 1–13**。

| 势力 | 花色 | 说明 |
|---|---|---|
| 魏 | ♠ | 黑 |
| 蜀 | ♥ | 红 |
| 吴 | ♣ | 黑 |
| 群 | ♦ | 红 |
| 神 | ★ | 紫 |
| 势 | ◆ | 橙 |

战力点数 = 综合体力 / 输出 / 生存 / 过牌的设计强度（数据写在 `HEROES.power`）：

| 点数 | 武将 |
|---|---|
| 13 | 神姜维 |
| 12 | 势魏延 |
| 11 | 势周瑜、势邓艾 |
| 10 | 张飞、马超 |
| 9 | 小将军、吕布、关羽 |
| 8 | 虎痴·关山、赵云 |
| 7 | 白羽先生、诸葛亮 |
| 6 | 青鸾、貂蝉 |

**用法**：父子对战想势均力敌就挑点数相近的；想挑战 Boss 就选神将/势将。

势力配色：魏蓝 / 蜀绿 / 吴红 / 群金 / 神紫 `#6D4C9F` / 势橙 `#C86A27`。
神系列卡面带 ★，势系列带 ◆。

## 音效与手感

全部用 Web Audio 现场合成，不加载任何音频文件，右上角可开关音效与战鼓 BGM。

| 事件 | 音色 |
|---|---|
| 摸牌 / 出牌 | 竹板质感的短噪声 tick + 点击音 |
| **濒死** | 锯齿波 120→70Hz 长下滑 + 方波心跳 + 低噪声（紧张拖长音） |
| 出杀 | 锯齿波下滑 760→180Hz + 挥砍噪声 |
| 出闪 | 正弦上滑 + 高频擦声（金属格挡感） |
| **判定** | 翻牌噪声 + 泛音上扬短音（八卦阵翻开的那一下） |
| 受伤 1 点 | 方波 200→62Hz 闷响；**2 点以上**换成低频 150→45Hz 重击 + 长噪声（暴击） |
| 吃桃 | 三角波 + 泛音上滑（治愈感） |
| 发动技能 | 三音上行琶音（古筝味） |
| 胜利 / 失败 | 五声音阶上行旋律 / 四音下行低回 |
| 战鼓 BGM | 五声音阶随机音符 + 低频鼓点，每 0.9 秒一步（默认关） |

**打击感**：受伤震屏（2 点以上重震 +「重击 -N」大字飘红）、出杀卡牌飞行动画、
自己受伤时手机震动；日志下方实时显示牌堆 / 弃牌堆余量（联机模式不下发牌堆，自动隐藏）。

**语音播报**：出杀 / 出闪 / 吃桃 / 濒死 / 发动技能 / 装备 / 无中生有 时同步念白，
技能念的是四字典故台词（借箭→「草船借箭」、空城→「空城之计」、无双→「无双！」），
装备也有专属台词（青釭剑→「青釭出鞘」、八卦阵→「八卦阵起」），
音高 0.78、语速 0.88 压出旁白腔。右上角 🎙 可开关，260ms 内连打只念一次、新念白打断旧念白。
用的是浏览器自带中文 TTS，不加载音频文件：Windows 优先挑「云扬」等中文男声，iOS / 安卓用系统
中文音色，没有中文音色的设备自动静默。手机端需要点第一下解锁（与音效同一次手势）。

**战绩与成就**：本机自动记录总胜率、当前 / 最高连胜、15 将各自胜负（选将页「🏆 战绩」查看）。
七枚成就徽章：旗开得胜、三连胜、五连胜、绝地反击（1 血取胜）、毫发无损（满血取胜）、
以下克上（低 3 点战力取胜）、武将收藏家（15 将各赢一场）。

**AI 三档强度**（对手选「电脑」时可切换，选择会被记住）：
**陪玩**——约四成回合松懈、只挡致命的杀、心软了还会出桃救你；
**标准**——原有强度；**高手**——会算斩杀线（直伤够收人头不赌出杀）、空手先补牌。

## 移动端（iPad / 手机）

两个页面都做了响应式：游戏页 ≤640px 走手机档（选将 3 列、按钮 40px 触屏触点、手牌自动换行），
≤360px 改 2 列；触屏去掉双击缩放延迟与点按高亮。打印页按屏幕宽度等比缩放 A4 预览，
**打印输出不受影响**。手机上把 `game.html` 发到文件传输助手用浏览器打开即可直接玩。

移动端音效：手机浏览器要求音频必须在用户手势内"解锁"，页面已内置——
**进游戏后点第一下（选武将）就自动解锁**，之后音效正常。语音播报（TTS）同样在这一次手势里一并解锁。
注意 iOS 的物理静音键拨到静音档时，游戏音效也会跟着静音，属系统行为。

## 局域网对战（多人各用自己的设备）

**双击 `启动局域网.bat` 即开**：自动启动服务器（默认端口 8765），1.5 秒后自动弹出浏览器，
窗口里打印本机局域网地址。玩完关窗口即可。命令行等价用法：

```
python start_lan.py                # 默认端口，自动开浏览器
python start_lan.py --port 8766    # 端口被占用时换一个
python start_lan.py --no-browser   # 不自动开浏览器
```

**手机 / iPad 接入**：连上和电脑**同一个 Wi-Fi**，浏览器打开启动窗口里打印的
`http://192.168.x.x:8765` 地址（以窗口里最新打印的为准）。一人「创建房间」，
其他人凭 4 位房间号加入，双方「准备」后房主点「开始对战」。
支持观战、加电脑补位、掉线 180 秒内重连回原座位。

连不上时优先排查：第一次启动时 Windows 防火墙弹窗要**允许**并勾**专用网络**；
手机是否连的是主 Wi-Fi（访客网络通常隔离）；路由器重新分配过 IP 就以最新打印为准。

规则零改动：服务器只负责房间与网络，牌局由 `game.html` 里原引擎结算（Node 子进程加载），
状态只存在服务端并按视角对调后下发，对手手牌与牌堆不下发到客户端。
详见 `lan_server.py` 文件头注释的**四个接入点**。

## 平衡数据（15 将两两对打 16800 局）

不是随机配对，而是**每个武将都和其他 14 位各打一遍、双方各坐一次先手**，
每对武将用独立随机种子，所以每个人样本量相同、也不受先手优势干扰：

| 段位 | 武将（胜率） |
|---|---|
| 略强 | 诸葛亮 56.8% · 貂蝉 55.7% · 吕布 55.0% · 小将军 54.1% · 白羽先生 54.0% |
| 中间 | 势邓艾 53.8% · 势魏延 53.7% · 虎痴·关山 51.0% · 神姜维 49.5% · 马超 47.8% · 赵云 47.8% |
| 偏弱 | 关羽 45.0% · 张飞 44.3% · 势周瑜 40.9% · 青鸾 40.5% |

全部落在 40.5%–56.8%，平均偏离 5.2 个百分点；判和 0%，平均 3.9 轮分胜负。
想自己复测：`node tests/game.test.js`（随机 400 局）或写个循环两两对打。

> 这一版含【诸葛连弩】+ 9 张装备 + 11 张战术牌。装备让"每回合挡一刀"类效果
> （静澜、八卦阵）价值上升，精算防御型受益；战术牌奖励"杀多、牌多、血厚"——
> 关山一度冲到 69.6%（酒刀+猛力一刀 3 点、5 血配【斗志】越挨打牌越多），
> 为此把【斗志】从摸 2 收敛为摸 1，他回到 51%。拆桥/顺手能拆装备，
> 也顺手压了一头"装备型"武将。牌堆同步扩到 75 张（杀 28 / 闪 12 / 桃 8）。
> 神姜维战力 13 点但胜率中游，是因为"多刀"天然被反击型（青鸾【惊鸿】）克制；
> 青鸾、势周瑜仍偏弱，靠操作可以补回来。AI 对 AI 只能说明"没崩"，真人玩起来的
> 强弱还看操作：空城、离间、静澜这类需要判断的技能，孩子用得好会比表里更强。
